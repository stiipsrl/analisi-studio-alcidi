lightbulb Raccomandazione Tecnica

Si consiglia di utilizzare il formato XML Export Xmed come sorgente primaria. Questo formato contiene tutte le informazioni necessarie per generare il tracciato IMPPN TeamSystem per fatture di vendita con incasso contestuale (tipologia professionista/studio medico). La struttura semplificata riduce i tempi di sviluppo e minimizza il rischio di errori di mapping.

Analisi Intelligente delle Descrizioni

Assegnazione automatica dei conti contabili tramite parole chiave

info Requisito Funzionale Critico

Oltre ai dati standard presenti nelle fatture (regime IVA, modalità di pagamento, importi), il programma di conversione dovrà effettuare un'analisi semantica del testo della descrizione di ogni riga fattura per identificare parole chiave specifiche e associare automaticamente il ricavo al conto contabile appropriato.

La mappatura tra parole chiave e conti contabili verrà concordata con Studio Alcidi & Partners in fase di sviluppo, in modo da riflettere esattamente il piano dei conti utilizzato per Medlight.

  • label

  • label

  • label
    "visita", "consulto" → Conto prestazioni mediche
  • label
    "chirurgia", "intervento" → Conto prestazioni chirurgiche
  • label
    "laser" → Conto trattamenti laser

Durante lo sviluppo verrà organizzato un incontro con Studio Alcidi per definire: la lista completa delle parole chiave da riconoscere, i codici dei conti contabili corrispondenti nel piano dei conti di Medlight, eventuali regole speciali o eccezioni, e il conto di default da utilizzare per le voci non classificabili automaticamente.

Flusso Operativo dell'Applicativo

upload_file

1. Esportazione da Xmed

L'operatore esporta le fatture dal gestionale Xmed in formato XML. Può selezionare un periodo o un gruppo di fatture da convertire.

folder_open

2. Caricamento nel Convertitore

Avvio dell'applicativo desktop e caricamento del file XML o selezione file. L'applicativo mostra l'anteprima delle fatture rilevate.

settings

3. Verifica Configurazione

Controllo parametri: codice ditta TeamSystem, conti di ricavo, conto cassa/banca per incasso. La configurazione viene salvata per usi successivi.

play_circle

4. Generazione File IMPPN

Click su "Genera IMPPN". L'applicativo converte ogni fattura in un record a lunghezza fissa secondo le specifiche TRAF2000 v3 e genera il file di output.

download

5. Importazione in TeamSystem

Il file generato viene importato in TeamSystem tramite la procedura IMPPN. Si consiglia di utilizzare prima la funzione "Controllo file" per validare i dati.

info

Note sulla Soluzione Proposta

L'applicativo desktop rappresenta la soluzione ottimale per questo caso d'uso: nessuna dipendenza da connessione internet, nessun canone mensile per servizi cloud, massima privacy dei dati che rimangono in locale. Il software può essere installato su tutte le postazioni necessarie senza costi aggiuntivi di licenza.

savings Vantaggi Economici per il Cliente
  • • Costo una tantum - nessun abbonamento mensile o annuale
  • • Installazioni illimitate - utilizzabile su più PC senza costi aggiuntivi
  • • Nessun costo infrastruttura - non richiede server o hosting
  • • Autonomia operativa - funziona offline, senza dipendenze esterne
support Supporto e Manutenzione

Al termine dello sviluppo è previsto un periodo di supporto per assistenza all'installazione, configurazione iniziale e risoluzione di eventuali problematiche riscontrate nei primi utilizzi. Eventuali evoluzioni future (nuovi formati di input, campi aggiuntivi IMPPN) potranno essere quotate separatamente.
