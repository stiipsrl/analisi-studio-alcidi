business

Contesto del Progetto

Medlight S.r.l. utilizza il gestionale Xmed per la gestione delle prestazioni mediche e la fatturazione. Le fatture di vendita devono essere trasferite nel gestionale TeamSystem (tramite procedura IMPPN) per la contabilizzazione da parte dello Studio Alcidi & Partners. Attualmente questo processo richiede inserimento manuale o rielaborazione dei dati.

Flusso Operativo Completo

medical_information

1. Gestione Fatture in Xmed

Medlight gestisce le prestazioni e genera le fatture nel gestionale Xmed. Le fatture vengono emesse con tutti i dati necessari: anagrafica paziente, prestazioni, importi, regime IVA.

download

2. Export XML da Xmed

Periodicamente (settimanale/mensile) l'operatore esporta le fatture da Xmed in formato XML. L'export può contenere più fatture in un unico file.

desktop_windows

3. Conversione con Applicativo Desktop

L'operatore avvia il convertitore, carica il file XML, verifica l'anteprima delle fatture e genera il file TRAF2000 con un click. Il file viene salvato nella cartella desiderata.

upload

4. Importazione in TeamSystem

Lo Studio Alcidi importa il file generato tramite la procedura IMPPN di TeamSystem. Prima dell'importazione può eseguire il "Controllo file" per validare i dati.

verified

5. Contabilizzazione Automatica

TeamSystem registra automaticamente le fatture di vendita con incasso contestuale, creando le anagrafiche clienti mancanti e le scritture contabili corrette.
